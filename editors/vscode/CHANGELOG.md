# Change Log

## 0.1.0

- Initial release: TextMate grammar and language configuration for `.httt`
  (Hat Trick text templates). Highlights all tag families (`{#if}`/`{#each}`/
  `{#with}`, `{/…}`, `{>partial}`, `{!comment}`, `{@debug}`, `{?var:}`/`{?:}`/
  `{:name}`, simple binds), trim markers, scope walks (`..\`), `$` references,
  lambda calls, and string/numeric/boolean literals. Host text is left plain.
